# Quake Bird (`quake-bird`)

A flappy-style arcade game for the panel: **tap to flap**, thread the pipe
gaps, chase your best score. Original canvas artwork; the pipes follow your
runtime accent color and the page theme.

## Options

- **Player initials (optional)** — 1–3 letters; overrides the initials entered
  in the game. Scores are recorded under them on the shared high-score server
  (arcade style: same initials = same player).
- **Server URL (advanced)** — base URL of the shared score server (same one
  kitten-cannon uses). **Clear it to play offline**; your best then stays on
  this PC.

## Notes

- Online leaderboards use the free community score server — see
  [`SCORE-API.md`](../SCORE-API.md) for the API and self-hosting instructions.
