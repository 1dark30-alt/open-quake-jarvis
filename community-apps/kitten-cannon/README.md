# Kitten Cannon (`kitten-cannon`)

A touch remake of the classic Kitten Cannon flash game: **drag or hold the
arrow buttons to aim, tap FIRE to launch**, and bounce off trampolines and TNT
for distance. Includes a persistent mute button.

## Options

- **Initials** — your 3-letter arcade initials; scores are recorded under them
  on the shared high-score server (same initials = same player).
- **Server URL (advanced)** — base URL of the score server. **Clear it to play
  fully offline**; high scores then stay on this PC.

## Notes

- Online leaderboards use the free community score server — see
  [`SCORE-API.md`](../SCORE-API.md) for the API and self-hosting instructions.
